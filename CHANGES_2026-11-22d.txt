Code (verify.py)
1. Syntax is checked for the whole file before duplicate keys are reported. A cut-off file is HOLD (INPUT-UNPARSEABLE) whether or not it repeats a key. A readable file with a repeated key is still FAIL (INPUT-DUPKEY). AMBIGUITY_LOG.txt entry 37, ERRATA.txt E-007.
2. Integers longer than 20 characters are read as out of profile and never converted, so the verdict no longer depends on the interpreter's integer-string limit. Entry 38, E-008.
3. Missing sequence numbers and declared gaps are held as ranges. A seq of 9007199254740991 no longer exhausts memory. Entry 39, E-009.
4. A number written with a fraction or very long digits no longer prints a memory address in a detail line. E-011.
